# ซาเล้งดิจิทัล · Trash to Cash

โปรเจกต์ React + Vite สำหรับทดลองนัดขายวัสดุรีไซเคิลในชุมชน สร้างจากหน้าเว็บและไฟล์ที่เบราว์เซอร์ของ [เว็บเดโมซาเล้งดิจิทัล](https://saleng-digital-try.vividwasp4096.chatgpt.site/) ใช้งานจริง โดยถอดหน้าจอออกเป็น JSX และแยกโค้ดฐานข้อมูลออกจากหน้าจอ ชื่อไฟล์ คอมโพเนนต์ และโครงสร้างโฟลเดอร์จัดขึ้นใหม่สำหรับพัฒนาต่อใน VS Code

## เปิดบนเครื่อง

1. ติดตั้ง Node.js 22.12 ขึ้นไป พร้อม npm
2. ใน VS Code เลือก **File → Open Folder…** แล้วเปิดโฟลเดอร์ `saleng-digital` ที่มี `package.json`
3. เปิด **Terminal → New Terminal** แล้วรัน

   ```sh
   npm ci
   npm run dev
   ```

4. เปิด URL ที่ Vite แสดงในบรรทัด **Local** ปกติเป็น `http://localhost:5173` หน้าแรกจะแสดงภาพรวมของผู้ขาย เมื่อบันทึกไฟล์ใน VS Code หน้าตัวอย่างจะอัปเดตเอง

สำหรับทดสอบเวอร์ชันที่ build แล้ว ให้รัน `npm run build` ตามด้วย `npm run preview` แล้วเปิด URL ที่แสดงใน Terminal ไฟล์เว็บสำหรับ static hosting อยู่ใน `dist/` และอ้างอิงรูปกับสคีมาจากรากของโดเมน

## ติดตั้ง APK บน Android

ดาวน์โหลด [Saleng Digital รุ่น 1.0.0 สำหรับ Android](https://github.com/Chawakornn/saleng-digital/releases/download/v1.0.0/Saleng-Digital-1.0.0.apk) หรือกด **ดาวน์โหลด APK สำหรับ Android** บนหน้าเว็บ แล้วเปิดไฟล์บนมือถือเพื่อกดติดตั้ง แอปรองรับ Android 8 ขึ้นไปที่มี Android System WebView รุ่นปัจจุบัน เมื่อเปิดแอปครั้งแรกในโหมดเครื่องบินจะเห็นข้อมูลสาธิตทันที

APK เก็บรายการและรูปภาพในพื้นที่ของแอปบนเครื่องนั้น เมื่อปิดแล้วเปิดใหม่ข้อมูลยังอยู่ เวอร์ชันเว็บเก็บข้อมูลแยกตามแท็บ ทั้งสองเวอร์ชันใช้บัญชีตัวอย่างสำหรับสลับบทบาทระหว่างพรีเซนต์

### สร้าง APK อีกครั้งบน macOS หรือ Linux

ติดตั้ง Node.js 22.12 ขึ้นไป, Python 3, JDK 21, Android SDK Platform 35 และ Build Tools 37.0.0 ตั้งค่า `JAVA_HOME` และ `ANDROID_HOME` ให้ชี้ไปที่ JDK และ Android SDK จากนั้นเรียก `npm ci` และ `npm run build:apk` เพื่อสร้างไฟล์ `public/downloads/saleng-digital.apk` เมื่อเรียก `npm run build` ไฟล์นี้จะถูกคัดลอกเข้าเว็บที่ `dist/downloads/`

เครื่องที่ใช้สร้างรุ่นนี้เก็บกุญแจลงนามและไฟล์รหัสผ่านไว้ใน `.android-signing/` ภายในโปรเจกต์ ให้สำรองโฟลเดอร์นี้ในที่ส่วนตัวสำหรับออกอัปเดตที่ติดตั้งทับรุ่นเดิม หากย้ายเครื่อง ให้ตั้ง `SALENG_KEYSTORE` เป็นพาธไฟล์ PKCS12 ที่มี alias `saleng` และ `SALENG_PASSWORD_FILE` เป็นพาธไฟล์รหัสผ่าน UTF-8 หนึ่งบรรทัด

## เพิ่มเว็บไว้ที่หน้าจอโฮม

เว็บรองรับการติดตั้งเป็น Progressive Web App (PWA) โดยไม่ต้องติดตั้งแอปจาก App Store หรือ Google Play:

1. Deploy เว็บบนโฮสต์ที่ให้บริการผ่าน HTTPS เช่น Vercel
2. เปิด URL บนมือถือและโหลดหน้าเว็บขณะออนไลน์อย่างน้อยหนึ่งครั้ง เพื่อให้เว็บแคชไฟล์สำหรับใช้งานออฟไลน์
3. Android: เปิดเมนูเบราว์เซอร์แล้วเลือก **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
4. iPhone/iPad: เปิดด้วย Safari แตะ **แชร์ → เพิ่มไปยังหน้าจอโฮม**

PWA ใช้หน้าจอ React ชุดเดิมและเปิดแบบเต็มหน้าจอเมื่อเปิดจากไอคอน แอปนี้ยังเก็บข้อมูลในเบราว์เซอร์ของอุปกรณ์แต่ละเครื่อง ไม่ได้ซิงก์ข้ามผู้ใช้ และการรองรับออฟไลน์ไม่ทำให้ข้อมูลที่ยังไม่เคยโหลดพร้อมใช้งานโดยอัตโนมัติ

## ลองใช้งาน

- เปิดเมนู **จองขายวัสดุ** ในบทบาทผู้ขาย ระบุน้ำหนัก เลือกรอบ แล้วกด **ยืนยันจองรอบ** เพื่อเปิดรายละเอียดรายการ
- ใช้ตัวเลือก **ดูเว็บในบทบาท** ด้านบนเพื่อสลับระหว่างผู้ขาย ร้านรับซื้อ ผู้ดูแลชุมชน และแอดมิน ข้อมูลในแท็บเดียวกันจะติดตามไปด้วย
- เปิดหน้า **รายการของฉัน** หรือ **รายการขาย** แล้วกด **ดาวน์โหลด CSV** เพื่อนำข้อมูลไปเปิดในโปรแกรมตารางคำนวณ

## ขอบเขตของข้อมูล

รุ่นนี้จำลองการทำงานทั้งหมดในเบราว์เซอร์ตามเดโมต้นฉบับ โดยใช้ SQLite ผ่าน sql.js ข้อมูลและภาพแนบเก็บใน `sessionStorage` ของแท็บ รีเฟรชแล้วข้อมูลยังอยู่ การสลับบทบาทใช้บัญชีตัวอย่าง และข้อมูลแต่ละเครื่องแยกจากกัน

หากแก้สคีมาหรือข้อมูลตั้งต้น ให้เปิดเว็บในเซสชันใหม่เพื่อสร้างฐานข้อมูลชุดใหม่ หรือใช้ **Developer Tools → Application → Session Storage** ลบรายการที่ขึ้นต้นด้วย `saleng-` ของเว็บบน localhost แล้วรีโหลด วิธีหลังจะล้างรายการทดลองที่เคยบันทึกไว้ในแท็บนั้น

หากจะพัฒนาต่อเป็นระบบหลายผู้ใช้ จุดเชื่อมต่ออยู่ใน `src/main.jsx` ซึ่งจัดการ `/api/state`, `/api/action` และ `/api/image` ในเบราว์เซอร์ ส่วนการดาวน์โหลด CSV ทำจากข้อมูลของบทบาทปัจจุบัน ระบบบัญชีผู้ใช้จริงและการจัดเก็บข้อมูลร่วมกันต้องเพิ่มฝั่งเซิร์ฟเวอร์
